##Fider App

Work in progress.

Fider is an open source feedback platform. Users can submit ideas, vote on feature requests and discuss suggestions, helping teams prioritise what to build.
Application repository for my Fider deployment project on Amazon EKS. The focus is Docker packaging, local development and GitHub Actions CI, with the goal of publishing container images to Amazon ECR.

Related repositories: fider-infra and fider-gitops.
